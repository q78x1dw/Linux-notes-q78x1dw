# Basics of lua

## interactive
`lua -i`

## scripting
`lua file.lua`

## shebang
`#!/usr/local/bin/lua`

## comments
One line ` -- comment_content`

Multi lines
```lua
--[[
    comment content
--]]
```

*No nested comments*

## identifiers

*same as C*

## variables

variables are *global* by default
undefined vars are nil

`> b = nil` to delete b.
