# procedure control

```lua
if(bool_expression)
then
    --[[expressions that will be executed when true --]]
end
```

```lua
if(bool_expression)
then
    --[[statements--]]
else
    --[[statements--]]
end
```

**caution!!** 0 is considered true.

multiple if else

```lua
if(bool1)
then
    --[[exec when bool1 true--]]
elseif(bool2)
then
    --[[exec when bool2 true--]]
end
```
